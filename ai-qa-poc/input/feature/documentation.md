# Supporting documentation — WorkPod

> Placeholder for POC-1. Whatever product documentation exists (specs, Figma
> notes, release notes, API docs) goes here so the Thinking Agent can separate
> "the requirement says" from "the documentation implies".

## Navigation

* The WorkPods area is reachable from the main navigation.
* A WorkPod detail page has tabs, including Comments.

## Terminology

| Term | Meaning |
|---|---|
| WorkPod | A container for related tasks, comments and files. |
| Comment | A message on a WorkPod, optionally carrying attachments. |
| Attachment | A file attached to a comment. |

## Notes for the Thinking Agent

* Anything not stated here or in `requirement.md` is a **gap**, to be reported
  at Gate 1 — not filled in with a plausible guess.
* Documentation is not authority over observed behaviour. When the two differ,
  that difference is itself a finding.
